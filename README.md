# KasirKu

**Hitung cepat, jualan tenang.**

KasirKu adalah aplikasi kasir untuk warung dan toko kecil. Semua kebutuhan kasir harian ada di satu tempat, dan semua data tersimpan di perangkat sendiri, tanpa server.

## Yang bisa dilakukan KasirKu

- Pindai barcode atau ketuk nama produk, total langsung terhitung otomatis.
- Struk bisa dikirim lewat WhatsApp atau dicetak ke printer Bluetooth 58 mm.
- Pembayaran tunai atau QRIS.
- Laporan omzet dan laba, rekap harian, dan daftar produk terlaris.
- Catatan kasbon pelanggan.
- Cadangan data, supaya riwayat jualan tetap aman jika ganti perangkat.
